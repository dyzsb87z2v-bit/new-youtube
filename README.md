# بعدش چی شد؟

کانال مستند کوتاه (۶۰ ثانیه، عمودی) دربارهٔ **ادامهٔ واقعی** اتفاقات معروف:
بعد از اینکه توجه مردم تمام شد، چه اتفاقی افتاد؟

> امضای کانال: هر قسمت با دو تاریخ شروع می‌شود — **«آن زمان»** و **«امروز»** —
> و با یک پاسخ کامل تمام می‌شود. هیچ قسمتی مخاطب را برای فهمیدن نتیجه به قسمت بعد نمی‌فرستد.

## ساختار مخزن

| مسیر | محتوا |
|---|---|
| [`docs/channel-bible.md`](docs/channel-bible.md) | هویت، شاخه‌ها، لحن، قالب عنوان، قواعد اخلاقی |
| [`docs/production-pipeline.md`](docs/production-pipeline.md) | زمان‌بندی ۶۰ ثانیه، تقسیم کار، مشخصات خروجی، چک‌لیست انتشار |
| [`docs/pilot-evaluation.md`](docs/pilot-evaluation.md) | چطور سه قسمت آزمایشی را بسنجیم و تصمیم بگیریم |
| [`templates/`](templates/) | قالب قسمت، کارت امتیازدهی موضوع، دفتر منابع و مجوزها |
| [`episodes/`](episodes/) | سه قسمت آزمایشی (پیش‌نویس سناریو + منابع برای راستی‌آزمایی) |
| [`topics/backlog.md`](topics/backlog.md) | فهرست موضوعات کاندید برای هر پنج شاخه |
